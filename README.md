# 🧠 VivArt Frontend – Auction & Social Media Platform

AuctionGram is a unique web application that combines the thrill of **auctions** with the interactive features of a **social media platform**. Inspired by platforms like Instagram, users can post images, like/comment, follow each other, and also **place bids** on items posted by others.

## 🔥 Features

### 🛒 Auction System
- Create auction listings with images, descriptions, starting price, and duration
- Bidding system with bid history and highest bidder tracking
- Automatic winner selection and notification upon auction end
- (Note: Real-time bidding with live updates is planned for future development)

### 📷 Social Media Features
- User profiles with avatars, bio, and post history
- Follow/unfollow system
- Like and comment on posts
- Newsfeed from followed users
- Explore trending auctions and posts

### 👥 Authentication & Security
- User registration and login
- Password hashing and session management
- Role-based access (e.g., admin, user)

### 🧰 Admin Panel
- Manage users, reported content, and auction rules
- Analytics dashboard

## 🛠️ Tech Stack

- **Frontend:** React.js with Bootstrap for UI components
- **Backend:** Flask (Python)
- **Database:** MongoDB
- **Authentication:** JWT and OAuth (e.g., Google OAuth)
- **File Upload:** Cloudinary or Firebase Storage
