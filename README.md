# 📸 AuctionGram - Social Auction Platform

AuctionGram is a unique web application that combines the thrill of **auctions** with the interactive features of a **social media platform**. Inspired by platforms like Instagram, users can post images, like/comment, follow each other, and also **bid in real-time** for items posted by others.

## 🔥 Features

### 🛒 Auction System
- Create auction listings with images, descriptions, starting price, and duration
- Real-time bidding with countdown timer
- Automatic winner selection and notification
- View bid history and highest bidder

### 📷 Social Media Features
- User profiles with avatars, bio, and post history
- Follow/unfollow system
- Like and comment on posts
- Newsfeed from followed users
- Explore trending auctions and posts

### 👥 Authentication & Security
- User registration and login
- Password hashing and session management
- Role-based access (e.g., admin, user)

### 🧰 Admin Panel (Optional)
- Manage users, reported content, and auction rules
- Analytics dashboard

## 🛠️ Tech Stack

- **Frontend:** React.js / bootstrap
- **Backend:**  Flask 
- **Database:** MongoDB 
- **Authentication:** JWT / OAuth  
- **Real-time Bidding:** WebSockets (Socket.IO)  
- **File Upload:** Cloudinary / Firebase Storage
